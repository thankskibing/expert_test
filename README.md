# 퍼소나 도출 검증 사이트

메디큐브 부스터프로 리뷰 3,601건과 사용자 인터뷰 6명(U1~U6)에서 데이터 퍼소나 3개·정성 퍼소나 3개가 어떻게 도출됐는지, 전문가가 원자료부터 확인하고 평가하는 사이트입니다.

## 페이지
0 개요 · 1 리뷰 데이터 · 2 핵심 리뷰 · 3 정성 인터뷰 · 4 행동 변수·그룹 · 5 결과 퍼소나 · 6 도출 과정·교차 검증 · 7 평가하기

## 개발
```bash
npm install
npm run dev     # 로컬 미리보기
npm run build   # dist/ 생성
```

## 데이터
`src/data/*.json`은 재분류 결과 엑셀과 두 퍼소나 PDF에서 생성했습니다. 리뷰 원문은 수정하지 않았습니다.

## 평가 응답 저장
`docs/apps-script.gs`를 응답용 구글 시트의 Apps Script로 배포한 뒤, 웹 앱 URL을 Vercel 환경변수 `VITE_EVAL_ENDPOINT`에 넣고 재배포합니다.

## 배포
Vercel에서 이 저장소를 Import하면 설정 없이 배포됩니다(Framework: Vite). 검색 엔진 노출은 막아 두었습니다.
